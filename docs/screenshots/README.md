# Screenshots

The main `README.md` references these files. Drop PNGs here with the
exact names and they render automatically. Recommended: 1600px wide,
PNG, OBS dark theme, no personal info on screen.

| File | Shot to capture |
|---|---|
| `agent-dock.png` | The **Agent** tab mid-conversation: a user request + tool cards (`✓ ran`) + the agent's reply. |
| `overlay.png` | OBS canvas showing a generated overlay live (e.g. a neon countdown / chat box). |
| `slash.png` | The Agent tab after typing `/help`, showing the shortcut list. |
| `settings.png` | The **Settings** tab with the model field + the tool-calling validation badge. |

How to grab them quickly:

```bash
./start.sh                 # bring the dev stack up
# arrange the dock + scene in the containerized OBS, then screenshot
```

Optional extras you can add (then reference in the README):
`scene-preset.png`, `dry-run-confirm.png`.
